# Simple Markdown Table Generator

A hyper-minimalist tool designed to convert raw text data (CSV-style) into clean Markdown tables instantly. Part of the **Fridge Combo** series.

## 🚀 Core Philosophy
- **1 Tool / 1 Action**: Focuses solely on markdown table conversion.
- **Performance**: Ultra-lightweight, browser-only, and fast on any device.
- **Privacy**: No login, no tracking, and no ads. Your data never leaves your browser.

## 🛠 Features
- **Instant Conversion**: Paste your comma-separated or tab-separated data and get a Markdown table.
- **One-Click Copy**: Quickly copy the result to your clipboard.
- **Minimalist UI**: Clean, high-contrast interface following the Fridge Combo design system (15px border-radius).

## 📖 How to Use
1. Enter your data in the input area (use commas or tabs as delimiters).
2. The Markdown table is generated in real-time or via a single click.
3. Use the "Copy" button to grab the code for your README or documentation.

## 📝 Privacy Policy
- **No Login Required**: Start using it immediately.
- **No Tracking**: No cookies, no analytics.
- **No Ads**: A distraction-free experience.
- **Browser-Only**: All processing is done locally on your machine.
